Grounding selection, in order

StepCodeWhat it does
1. Candidate positionscandidatePositions() grounding.ts:72 Normalises every position the extraction mentions. Uses key mistake + opponent action + raw transcript as context — the practitioner states their side far more often than the tidy summary does.
2. LoadloadGroundingRecords() index.ts:604 Service-role read of coaching_records for those positions, limit 200 with no order by. Never throws — grounding is enrichment. The 200 is the one number in this path with no argument attached to it: 9 positions exceed it alone, and IDF is then computed over the truncated slice, so it shifts the ordering and not just the membership. grounding_candidates = 200 means "at least 200", not "200".
3. gi filterfilterByGiContext() index.ts:488 Before ranking, so an inapplicable record cannot occupy a slot. Recording overrides the UI toggle (#60).
4. RankrankRecords() grounding.ts:179 Drop rejected + contested → gate on ≥2 distinct matched terms → order by IDF × domain weight → certified first → cap at 20.
5. ArmassignGrounding() Assigned only when records are available, so withheld means "had them, withheld them". Keyed on the idempotency id so a retry cannot flip the arm.
6. RendergroundingSection() grounding.ts:276 Guidance first, mechanics last. Returns '' when empty, so an ungrounded prompt is byte-identical to the pre-grounding prompt.
7. Inject{{GROUNDING}} in bjjPrompts.ts:150 The only door. Filled client-side at ClaudeProvider.ts:89. Not filled server-side — see lesson 1.

The magic numbers, and what bought them

ConstantValueEvidence
GROUNDING_RECORD_LIMIT20Cost is not the constraint (~2,100 tokens). Dilution is: half-guard-bottom alone has 145 records.
GROUNDING_MIN_RELEVANCE2Ungrounded beat top-20 grounded two-to-one in a blind trial. A bar of 2 keeps 17 of 23 sessions grounded while cutting the median injected set from 25 to 4.
DOMAIN_TERM_WEIGHT2allowing and kimura each appeared in exactly 13 of 295 records — IDF scored them identically and file order picked the winner.
MIN_QUOTE_WORDS8Below it a quote is a fragment backing nothing. No repairable quote in either corpus came near the floor.
fetch limit200Nothing. The only constant here with no measurement behind it and no comment defending it. See lesson 2.
Cue word cap25Enforced in both CoachingService.ts and the system prompt. CLAUDE.md rule 6: change one, change both.

Glossary — the sessions.grounding_* columns

ColumnMeaningWhat to do about it

= 'no_position'The free-text position never resolved to a canonical id — usually the side was unknown, or it was a submission.Fix the taxonomy or extraction. Mining more will not help.
