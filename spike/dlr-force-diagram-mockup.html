An animated de la riva force diagram: two clean two-tone figures form the base position; an animated overlay shows the heel driving up into the opponent's hamstring, a pulsing pressure zone, the opponent's forward push being blocked, and a base support point — all drawn from a structured mechanical spec.

The cue

From de la riva, keep your sweeping leg's heel digging into the opponent's hamstring to prevent their push.

Annotation grammar

Force direction (animated)
Pressure / active contact
Opponent's force (blocked)
Base / support point

Structured spec (LLM → renderer)

{
  "base": "de-la-riva",
  "annotations": [
    { "type":"force",   "anchor":"hook_heel",
      "toward":"opp_hamstring", "intensity":"high" },
    { "type":"pressure", "anchor":"heel_on_hamstring" },
    { "type":"counter",  "anchor":"heel_on_hamstring",
      "opposes":"opp_forward_push" },
    { "type":"base",     "anchor":"posting_forearm" }
  ]
}

Renderer contract: everything grey is the base skin (a keypoint skeleton — swappable). Everything coloured is drawn deterministically from the spec above: each annotation's anchor/toward are semantic roles the renderer resolves to coordinates via the position's role map. Arrowheads convey direction statically; animation is an additive layer for the hero view only.
