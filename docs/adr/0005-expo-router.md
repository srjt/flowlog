# 0005. Expo Router over React Navigation

**Status:** accepted · **Date:** 2026-06-14

Navigation uses file-based routing via Expo Router. It gives faster iteration,
built-in deep linking, and alignment with Expo SDK 51+.

## Consequences

- Less flexibility for complex custom navigation flows.

## Considered options

- **React Navigation** — rejected: more boilerplate, slower to iterate at the
  MVP stage.
